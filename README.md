# 🔍 CareerLens AI

AI-powered resume analyzer for top tech companies.

## 🌐 Live Demo
https://careerlens-ai.streamlit.app

## ✨ Features
- 📄 Resume ATS scoring
- 🎯 Company match analysis
- 💡 AI improvement tips
- 📝 Cover letter generator
- 🎤 Interview questions
- 🗺️ Skills roadmap
- 📸 Resume screenshot analyzer
- 🏢 Google, Amazon, Meta, Microsoft

## 🛠️ Tech Stack
- **Frontend:** Streamlit
- **AI:** Groq API, LLaMA
- **Backend:** Python
- **Deployment:** Streamlit Cloud

## 🔧 Run Locally
git clone https://github.com/26Ritika/careerlens-ai
cd careerlens-ai
pip install -r requirements.txt
streamlit run app.py
